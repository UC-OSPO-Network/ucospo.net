The ORB Working Group maintains the **[Open Repository Browser (ORB)](https://juanis2112-repoexplorer.share.connect.posit.cloud/)**, an open source toolkit for finding and exploring the open source software a university produces. ORB started inside the Network's [Discovery Working Group](discovery.md) and is now an open source project in its own right, with contributors from outside UC.

**Hosts:** Juanita Gomez (ORB maintainer) and Virginia Scarlett

**Membership:** The community call is open to anyone. Voting membership of the working group is set out in ORB's [governance document](https://github.com/UC-OSPO-Network/orb-community/blob/main/GOVERNANCE.md).

## What this group does

The group looks after the upstream ORB project: architecture, features, data infrastructure, and code review. ORB is a small family of repositories:

- **[repofinder](https://github.com/UC-OSPO-Network/repofinder):** identifies and analyzes repositories affiliated with a university, using GitHub metadata and contributor analysis
- **[repoexplorer](https://github.com/UC-OSPO-Network/repoexplorer):** the interactive dashboard for exploring repositories, contributors, and activity, built in Python with [Shiny](https://shiny.posit.co/py/)
- **[orb-showcase](https://github.com/UC-OSPO-Network/orb-showcase):** a web application for presenting the data repofinder collects
- **[orb-community](https://github.com/UC-OSPO-Network/orb-community):** governance, code of conduct, contributing guide, and meeting summaries shared across the project

For background on the approach, see the [ORB paper](https://doi.org/10.48550/arXiv.2506.18359).

### ORB and Discovery

The two groups are related but distinct:

- The **ORB Working Group** maintains the open source toolkit. It is developer-focused and open to anyone, at UC or not.
- The **[Discovery Working Group](discovery.md)** is the UC OSPO Network's group for mapping UC open source. It runs the UC instance of ORB, alongside the project showcase and the UC-wide survey.

## Meetings

The group holds an open community call on the **first Tuesday of each month, 1–2pm Pacific**. Details and a calendar link are on the [events page](../../../events/index.md#orb-community-call). The call is aimed at people who want to work on the code, and users who want to follow along are welcome too.

The call isn't recorded. After each one the group publishes a short written summary in the [orb-community repository](https://github.com/UC-OSPO-Network/orb-community/tree/main/meetings).
